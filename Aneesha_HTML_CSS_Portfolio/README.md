# Aneesha — Personal Portfolio Website

A responsive personal portfolio website built with **HTML5 and CSS3 only** for the HTML & CSS Internship Project.

## Project description

This is a responsive personal portfolio website built using only HTML5 and CSS3, with no JavaScript, frameworks, or backend. It introduces me through a hero section, an About section with my education and career interests, six skill cards, three project cards that list the technologies used, and a contact section with my email and GitHub profile. The page uses semantic HTML elements, a sticky navigation bar with section links, CSS variables for a consistent colour palette, and CSS Grid and Flexbox for the layouts. Media queries adapt the design for desktop, tablet, and mobile screens without horizontal scrolling. Buttons, links, and cards have hover and keyboard-focus effects to make the site interactive and accessible.

## Sections

1. **Header / Navigation:** logo plus links to Home, About, Skills, Projects, and Contact
2. **Hero / Home:** name, career goal, short introduction, and buttons linking to Projects and Contact
3. **About Me:** biography, education, and career interests
4. **Skills:** six skill cards (HTML5, CSS3, JavaScript, Python, Flask, MySQL)
5. **Projects:** three project cards, each with a title, description, and technologies used
6. **Contact:** email, GitHub profile, and location
7. **Footer:** copyright line and name

## Features

- Semantic HTML5: `header`, `nav`, `main`, `section`, `article`, `footer`
- External stylesheet (`style.css`) with no inline styles
- CSS variables for the main colours (dark background, lime and teal accents)
- CSS Grid and Flexbox layouts
- Responsive breakpoints at 850px, 600px, and 360px, tested from 320px to 1440px with no horizontal overflow
- Hover and focus states on navigation links, buttons, skill cards, project cards, and contact links
- Respects the "reduced motion" accessibility setting

## How to run

1. Extract the ZIP file.
2. Open `index.html` in Google Chrome or Microsoft Edge.
3. Resize the window, or use DevTools device mode, to view the mobile layout.

No installation, JavaScript, framework, backend, or database is needed.
